# Campus Wallet

A student-focused budget and expense tracking web application built with HTML, CSS, and JavaScript.

## Features
- Add expenses and income
- Categorize transactions
- Set and update a monthly budget
- View remaining budget and spending summaries
- Review category-wise expenses
- Filter transactions by month, week, or all time
- Delete transactions
- Export transaction history as CSV
- Save data in the browser using localStorage

## How to run
No installation or build step is required.

1. Open `index.html` in Google Chrome, Firefox, or Microsoft Edge.
2. Add a transaction and set a monthly budget.
3. Your data is saved in the browser on the same device.

You can also open this folder in PyCharm and right-click `index.html` -> Open in Browser.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Note
This is a front-end prototype. Data is stored locally in the browser and is not synchronized between different users or devices.
